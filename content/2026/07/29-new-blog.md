汐猫みおです。いままでははてなブログでブログを書いていましたが、自作ブログへ移行しました。

## ブログを自作ブログにしたわけ

いままでは、はてなブログを使っていたのですが独自ドメインは有料プランでなければ使えないのと、もう少し軽くてデザインを自由にやりたいなと思っていました。  
そこで Cloudflare ならホスティングや画像保存など無料枠の範囲が大きくて、独自ドメインもやりやすいということでそうだ自作ブログだということで、はてなブログから自作ブログへ乗り換えることにしました。

## 技術スタック

このブログを作るにあたって、

- TypeScript
- Nuxt4
- Cloudflare Workers
- Cloudflare D1
- Cloudflare R2

を使って自作してみたいと思い、Gemini と Claude の力を借りながら作成してみました。  

サイト自体は Nuxt4 & TypeScript で作成して、ホスティングを Cloudflare Workers にてしていて、記事管理などは Cloudflare D1 で、画像は Cloudflare R2 という感じの構成になっています。

### 画像のアップロード

![2026-07-29-2](https://blog-asset.skyfelis.jp/posts/2026-07-29-2.webp)

R2 へ簡単に画像をアップロードして Markdown で貼り付けられるようにローカル環境でしか動作しない簡単なツールを作成してみました。  
このツールは、自分自身がアップロードしてるのかを判別するためにパスワード制にしてあって、裏で API とかでアップロードできるようになっています。ファイルを選択すると、WebP 形式に圧縮されて、ファイル選択が正しいか尋ねる画面が出て間違えていなければアップロードするを選択すると簡単に R2 へアップロードされるようになっています。

![2026-07-29-3](https://blog-asset.skyfelis.jp/posts/2026-07-29-3.webp)

アップロードが完了すると Markdown 形式のリンクがコピーできるようになっていて、コピーして編集中の記事に貼り付けるとちゃんと画像が表示されるという仕組みになっています。  
これで、はてなブログでブログ書いてる最中に画像を貼り付けるみたいな手軽さに記事をかけるようにしました。

セキュリティ的にローカル環境で、API キーなどをセットしないと使えないようになってるので第三者に無断でアップロードされるということは防いでいます。

## ブログを作った感想

実際にブログを作ってみて思ったことは、無料枠で結構使えるものは作れるんだなと。
自分用に便利ツールも作れたので今後はこのブログを使っていこうと思います。
